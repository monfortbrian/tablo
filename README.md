# Tablo - Smart Tables for Real Data

Paste any data. Get a beautiful, styled table in Figma. No manual setup.

## What it does
- Smart paste detection (CSV, TSV, markdown, spaces, tabs)
- 5 built-in themes
- Auto column alignment by data type
- Per-column alignment panel
- Export to CSV / JSON
- Google Sheets URL import (public sheets)

## Themes
Minimal · Stripe · Notion · Dashboard · Brutalist

## Keyboard shortcut
⌘ + Enter to create

## Who it's for
Designers building dashboards, admin panels, data tables, and reports
who are tired of dummy data and manual column resizing.
